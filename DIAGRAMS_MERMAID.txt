DIAGRAM 3: FLOWCHART - PROJECT CREATION, ASSIGNMENT & DEADLINE LOGIC (Chapter 3.2)
================================================================================
flowchart TD
    Start([Start]) --> Login["User Authenticates (Login)"]
    Login --> CheckRole{"Is User Project Manager?"}
    
    CheckRole -- Yes --> CreateProj["Create Project & Divide into Modules"]
    CreateProj --> AssignTask["Assign Task to Specific Developer"]
    AssignTask --> SetDeadline["Set Target Deadline Date & Time"]
    SetDeadline --> SaveDB[("Store in Cloud Firestore")]
    
    CheckRole -- No --> ViewAssigned["Developer Views Assigned Tasks"]
    SaveDB --> ViewAssigned
    
    ViewAssigned --> DevActions{"Developer Action"}
    DevActions -- Add Subtask --> Subtask["Create Subtasks under Task"]
    DevActions -- Post Comment --> Comment["Post Update / Comment"]
    DevActions -- Mark Done --> Complete["Mark Task as Completed"]
    
    Subtask --> SaveDB
    Comment --> SaveDB
    Complete --> DeadlineCheck
    
    subgraph Deadline_Status_Engine ["Deadline Status Engine"]
        DeadlineCheck{"Is Task Completed?"}
        DeadlineCheck -- Yes --> TimeCheck1{"Completed Time <= Deadline?"}
        TimeCheck1 -- Yes --> GreenState["Mark Status GREEN: On Time (Done)"]
        TimeCheck1 -- No --> OrangeState["Mark Status ORANGE: Completed Late"]
        
        DeadlineCheck -- No --> TimeCheck2{"Current Time > Deadline?"}
        TimeCheck2 -- Yes --> RedState["Mark Status RED: Overdue / Delayed"]
        TimeCheck2 -- No --> BlueState["Mark Status BLUE: In Progress"]
    end
    
    GreenState --> Monitor["PM Dashboard Real-Time Monitoring"]
    RedState --> Monitor
    OrangeState --> Monitor
    BlueState --> Monitor
    Monitor --> End([End])

DIAGRAM 4: ENTITY-RELATIONSHIP (E-R) DIAGRAM (Chapter 3.3)
================================================================================
erDiagram
    USER ||--o{ PROJECT : manages
    USER ||--o{ TASK : assigned_to
    USER ||--o{ COMMENT : writes
    PROJECT ||--|{ TASK : contains
    TASK ||--o{ SUBTASK : includes
    TASK ||--o{ COMMENT : receives

    USER {
        string uid PK
        string displayName
        string email
        string role "PM or Developer"
    }

    PROJECT {
        string id PK
        string title
        string description
        string managerId FK
        datetime createdAt
    }

    TASK {
        string id PK
        string projectId FK
        string title
        string description
        string assigneeId FK
        datetime deadline
        string status "Backlog, InProgress, Done"
        boolean isCompleted
        datetime completedAt
    }

    SUBTASK {
        string id PK
        string taskId FK
        string title
        boolean isCompleted
    }

    COMMENT {
        string id PK
        string taskId FK
        string authorId FK
        string text
        datetime timestamp
    }
